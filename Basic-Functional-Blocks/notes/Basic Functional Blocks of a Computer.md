Basic Functional Blocks of a Computer

A computer system is made up of three main functional blocks, which are connected using a bus.

1. Central Processing Unit (CPU)

The CPU is the brain of the computer. It performs all calculations and controls the operation of the entire system.

The CPU has three main parts:

a) Arithmetic Logic Unit (ALU)

Performs arithmetic operations such as addition, subtraction, multiplication, and division

Performs logical operations such as AND, OR, NOT, comparisons (>, <, =)

📌 Example: Adding two numbers or comparing two values

b) Control Unit (CU)

Directs and controls all activities of the computer

Generates control signals to tell other parts what to do and when

Controls the flow of data between CPU, memory, and I/O devices

📌 In simple words: CU acts like a traffic police, managing and coordinating all operations.

c) Registers

Very small and fast memory inside the CPU

Used to store data, instructions, or addresses temporarily during execution

Types of Registers:

User-visible registers  
Accessible by the programmer  
Store data and results temporarily  

Control and status registers  
Used by the CPU to control execution  
Store information like instruction address, status flags, etc.

2. Memory Unit

Stores data, instructions, and intermediate results

Supplies data and instructions to the CPU when required

Stores results after processing

📌 Example: RAM storing your program and input values while the computer is running.

3. Input/Output (I/O) Unit

Enables communication between the computer and external devices

Input devices: Keyboard, mouse, scanner  
Output devices: Monitor, printer, speaker  

📌 Function:  
Input unit sends data into the computer  
Output unit sends processed data out of the computer  

4. Bus

A communication pathway that connects CPU, Memory, and I/O units

Transfers data, addresses, and control signals

Types of buses (basic idea):

Data bus – carries data  
Address bus – carries memory addresses  
Control bus – carries control signals
